# Software Engineering Project Starter Code
## Computation

The system will find all of the positive factors of an input integer.

The input to the computation will be one positive integer. The computation will determine every positive integer that divides the input evenly.

For example, if the input is:

`12`

The output will be:

`1,2,3,4,6,12`

Another example is:

`6`

which produces:

`1,2,3,6`
